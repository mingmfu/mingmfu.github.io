I work on operating systems and formal verification. My research focuses on concurrent programs, synchronization, and weak memory models.

Recent work includes verified memory allocation and work stealing, as well as parallel rendering and tracing on mobile devices. Some of our work on synchronization is available in libvsync.

Software

libvsync

A library of verified synchronization primitives and concurrent data structures for weak memory architectures. Related to our VSync paper at ASPLOS 2021.

CertiuCOS2

A framework for proving that preemptive kernel implementations refine their abstract specifications, with a uC/OS-II case study. The code now builds with Rocq 9.2. The README covers the build, proof scope, and known assumptions. Research materials.
